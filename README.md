Human Pose Estimation using OpenCV



This project implements human pose estimation using OpenCV. It leverages pre-trained deep learning models to detect and estimate the poses of humans in images or video frames.

Features


Detect human poses in real-time using webcam or uploaded images/videos.
Visualize human body keypoints on images/videos.
Use OpenCV for image processing and model inference.


Requirements



Python 3.x

OpenCV

NumPy

TensorFlow / PyTorch (depending on your model)
